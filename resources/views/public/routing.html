Routing API

Flutcom handles routes natively using the browser's Hash (#), allowing you to navigate between views without reloading the page or configuring special servers.

1. Define Routes

Routes are centrally configured in the flutcom.config.js file by mapping a Hash to a physical HTML file:

export const routes = {
  home: "resources/views/public/home.html",
  about: "resources/views/public/about.html"
};

2. Navigation

Simply use conventional <a> tags pointing to the Hash. Flutcom will intercept the click and inject the view instantly:

<!-- Navigation without reload -->
<a href="#about">Go to About</a>

3. Hooks (Lifecycle)

You can execute JavaScript right before entering a route or right after loading it:

app.on('view:load', (viewName, el) => {
  if (viewName === 'about') {
    console.log('The About page has been rendered');
  }
});
