v1.4.1 Component Architecture

Modular Components.

Flutcom's component engine resolves raw HTML templates with native declarative custom tags and dynamic props. No Virtual DOM diffing overhead, no mandatory build compilation step. Just high-speed native template interpolation.

Components are plain .html files stored in resources/components/ with {{ prop }} and {{ slot }} placeholders. They are cached in volatile RAM upon initial fetch — subsequent usages incur exactly zero network overhead.

Custom Tag Shorthand

Mount directly as <flut-name> without wrapper elements or repetitive attributes.

In-Memory Template Cache

Templates are fetched once and saved in memory. Re-rendering cost is sub-millisecond.

Static Escape & Strict Mode

Precomputed HTML escaping map and strict event handling preventing script injection.

Slot Injection

Pass arbitrary HTML as children of custom tags to be injected into {{ slot }}.

View Template (Caller)
<flut-alert icon="bi bi-info-circle" title="Notice">
  <!-- Everything here replaces {{ slot }} -->
  <div class="font-mono text-xs">
    <span>Node Status:</span>
    <strong class=Live></strong>
  </div>
</flut-alert>
Component Template (alert.html)
<div class="alert-box">
  <h4>{{ title }}</h4>
  <p>{{ description }}</p>

  <!-- Injected child nodes arrive here: -->
  <div>{{ slot }}</div>
</div>

Creating Custom Components

Build your own reusable components in seconds. Any HTML file in resources/components/*.html is instantly mountable.

1 Create resources/components/stat-box.html 
<div class="p-6 rounded-2xl bg-zinc-950 border border-white/10">
  <div class="text-3xl font-black font-mono text-white">{{ value }}</div>
  <div class="text-xs font-mono text-zinc-500 mt-1 uppercase tracking-wider">{{ label }}</div>
  <div class="mt-3 text-xs text-zinc-400">{{ slot }}</div>
</div>
2 Use it declaratively in any view with <flut-stat-box> 
<div class="grid grid-cols-1 md:grid-cols-3 gap-4">
  <flut-stat-box value="4.1 KB" label="Bundle Size">Zero runtime bloat</flut-stat-box>
  <flut-stat-box value="0 ms" label="Hydration Delay">Instant DOM mount</flut-stat-box>
  <flut-stat-box value="100%" label="Native JavaScript">Zero external packages</flut-stat-box>
</div>
